# Code of conduct

Captain’s Log should be a safe, constructive project for contributors and users.

## Expected behavior

- Be respectful, specific, and patient.
- Critique ideas and code rather than people.
- Welcome different experience levels and explain decisions in public where practical.
- Protect other people’s privacy. Never post recordings, transcripts, credentials, device
  identifiers, private logs, or personal data in an issue or pull request.
- Disclose security concerns privately instead of demonstrating them against another person’s data
  or device.

Harassment, discrimination, threats, doxxing, sexualized conduct, and deliberate disruption are not
acceptable in project spaces.

## Reporting and enforcement

Use the private reporting route in [SECURITY.md](SECURITY.md) for security or conduct reports that
should not be public. Maintainers may edit or remove content and restrict participation when needed
to protect people or the project. Before publication, the maintainer must enable that private route
or provide a monitored replacement.
