## [0.1.0] - 2026-07-22

### Added

- Source-neutral local event lake, immutable audio/transcript storage, and rebuildable ClickHouse
  projections.
- Native macOS Review, Library, Automations, Settings, menu-bar status, and notifications.
- Deterministic, reversible workflows with bounded local-model selection slots.
- Optional Pocket compatibility adapter with explicit binding recovery and release.
- BLE-only Android recorder with an app-private durable queue and resumable verified transfer.
- AGPL-3.0-only community licensing with a Harmony Option Five contributor agreement and a separate
  negotiated commercial-licensing path held by Solomonoff Consultancy Ltd.

### Known limitations

- Android-to-Mac transfer has protocol and emulator coverage but still needs physical-radio
  validation before it is described as hardware verified.
- This first release contains source only. Production-signed and notarized application packages are
  deferred.
